# # 🎮 Character Resources

Небольшой учебный проект на Java, демонстрирующий работу с классами, объектами, конструкторами и преобразованием типов данных.

## 📖 Описание

Проект состоит из трех классов:

- **Resources** — хранит исходные ресурсы персонажа.
- **Character** — хранит характеристики персонажа после преобразования данных.
- **Practice** — главный класс программы, в котором создаются объекты, выполняется преобразование типов и выводится информация в консоль.

## 📂 Структура проекта

```
src/
├── Practice.java
├── Resources.java
└── Character.java
```

## ⚙️ Используемые технологии

- Java
- Объектно-ориентированное программирование (ООП)
- Конструкторы
- Примитивные типы данных
- Приведение типов (Type Casting)

## 🚀 Как работает программа

1. Создаются исходные данные о ресурсах персонажа.
2. Создается объект `Resources`.
3. Выполняется преобразование данных:
   - `long → int`
   - `byte → int`
   - `short → double`
   - `long → byte`
   - `boolean → byte`
4. Создается объект `Character`.
5. Информация о персонаже выводится в консоль.

## ▶️ Пример вывода

```text
Персонаж создан успешно!
Количество золота: 200
Количество серебра: 3900
Количество дерева: 2005.0
Здоровье: 97
Количество помощников: 1
Навстречу приключениям!
```

## 🛠️ Запуск проекта

Скомпилируйте файлы:

```bash
javac *.java
```

Запустите программу:

```bash
java Practice
```
